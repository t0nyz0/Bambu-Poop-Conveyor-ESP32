Printer event rules

Choose exactly when it runs.

Add any documented printer stage or print state, then give it independent timing.

Add a printer event

Stage names and print states follow the same MQTT status model used by the Bambu Lab Home Assistant integration. Substage meanings are printer-specific, so use those only when you know the numeric value.
Substage rules retain priority when events overlap. Saving a rule while its event is already active will not trigger the conveyor; it waits for the next event edge. Up to 16 rules can be stored.
