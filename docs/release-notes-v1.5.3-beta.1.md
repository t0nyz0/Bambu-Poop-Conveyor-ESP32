# v1.5.3 Beta 1

Temporary acceptance build for the previous-stable recovery flow. The Update screen uses a separate previous-stable feed and explains rollback using the selected release rather than naming an outdated version. v1.5.1 is the previous stable target; original v1.4.2 recovery files remain available to older clients.

Motor timing, saved settings, printer rules, USB provisioning, and Wi-Fi behavior are unchanged. This beta is not a public stable replacement until the physical rollback-and-return test passes.
